# C++ Coursework

Лабораторные работы по программированию на C++.

| Проект | Описание |
|---|---|
| [lab1-bmp-image-processing](./lab1-bmp-image-processing) | Обработка BMP-изображений: поворот, гауссово сглаживание |
| [lab2-oop-rpg-system](./lab2-oop-rpg-system) | RPG-система персонажей на принципах ООП |
| [lab3](./lab3) | Поиск подстроки через конечный автомат |
| [lab4](./lab4) | Визуализация графов (алгоритм Фрюхтермана-Рейнгольда) |
| [ones-complement](./ones-complement) | Арифметика чисел в обратном коде |
| [monte-carlo-integration](./monte-carlo-integration) | Интегрирование методом Монте-Карло с многопоточностью |

## Технологии
C++, CMake, работа с бинарными форматами, ООП, многопоточность, алгоритмы на графах и строках
