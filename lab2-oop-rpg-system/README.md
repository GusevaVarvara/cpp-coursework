# RPG-система персонажей (ООП)

Учебный проект по программированию (C++, 1 курс). Модель боевой RPG-системы, 
демонстрирует основные принципы ООП: инкапсуляция, наследование, 
разделение классов по ответственности.

## Основные сущности
Character, Race, Class, Weapon, Armor, Item, Potion, Pet, Enemy, Dice, Combat

## Технологии
C++, объектно-ориентированное проектирование
