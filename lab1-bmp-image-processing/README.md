# Обработка BMP-изображений

Учебный проект по программированию (C++, 1 курс). Обработка изображений 
в формате BMP реализована с нуля, без сторонних библиотек: ручной парсинг 
бинарного заголовка файла и работа с пиксельным буфером напрямую.

## Функциональность
- Поворот изображения на 90°
- Сглаживание гауссовым фильтром (свёртка)

## Технологии
C++, работа с бинарными файлами, реализация свёртки вручную
